# Inventory Management System

## Project Description

This project is a full-stack inventory management application built using 
Flask and SQLAlchemy. The application allows users to manage categories 
and products through a web interface.

Users can:
- Create, update, and delete products
- Create and delete categories
- Restock inventory
- View inventory statistics on a dashboard

The application demonstrates database normalization, CRUD operations, 
relationship management, transaction logic, and server-side validation.

## Installation Instructions

Clone the repository:

```bash
git clone <https://github.com/tengfive/cs665_project3>

Move into the project folder:

```bash
cd cs665_project3
```

Create virtual environment:

```bash
python3 -m venv venv
```

Activate virtual environment:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Running the Application

Run the Flask server:

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
